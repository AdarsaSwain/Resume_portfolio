Paste or upload a resume and get a finished one-page site with a hero, experience, projects, skills and contact. Download it, host it anywhere, or send it as a link.

Build my portfolio

How it works

  1. Add your resume

    Paste the text or drop in a PDF, TXT or Markdown file. Clear headings such as Experience, Projects and Skills give the best result.

  2. Pick a look

    Choose one of five designs and an accent colour, check it on desktop and phone, and fix any detail under Edit details.

  3. Download or share

    Save the site as a single HTML file you can host anywhere, or copy a link that opens the portfolio straight away.

Add the builder to your own site

The builder is one script and one tag. It keeps its styles to itself, fits the width you give it, and follows your page’s light or dark mode.

  • parse-endpoint sends resumes to your server for AI parsing.
  • share-url points share links at your own viewer page.
  • theme and accent set the starting look.
  • The portfolio-built event hands your page the data and the finished HTML.

See it running inside another page

<script src="/plugin/resume-portfolio.js" defer></script>

<resume-portfolio
  theme="midnight"
  accent="#0f8a5f"
  parse-endpoint="/api/parse"
  share-url="/view.html">
</resume-portfolio>

<script>
  document.addEventListener('portfolio-built', e => {
    console.log(e.detail.data, e.detail.html);
  });
</script>

Put your portfolio online

GitHub Pages

Create a repository named yourname.github.io, upload the file as index.html, and it is served at https://yourname.github.io. Guide

Netlify Drop

Rename the file to index.html, put it in a folder, and drag the folder onto Netlify Drop for a live link. Sign in to keep the site. Open Netlify Drop

Vercel

Put index.html in a folder, run npx vercel inside it, and follow the prompts. Add your own domain later from the dashboard. CLI docs

Your resume is read in this browser and is not uploaded. A share link holds the portfolio inside the link itself, so nothing is stored on a server.
